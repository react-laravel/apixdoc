# 请求历史与安全展示

在线测试中的「历史」保留当前标签页最近 20 次请求，按账号、项目和接口隔离。
本轮改进只涉及历史展示和本地交互，不改变请求发送、服务端权限、数据库或迁移。

## 查找与操作

- 支持搜索列表中显示的请求地址或环境名称，不区分大小写，忽略首尾空格。
- 方法和结果筛选可组合使用。结果区分成功/重定向、HTTP 错误、请求失败/取消和无响应结果。
- 显示筛选数量；没有匹配结果时可清空筛选，原始历史不会被删除。
- 搜索框中按 Escape 可清空关键词；点击清空搜索后，焦点回到输入框。
- 每条历史显示方法、地址、时间、环境、状态、耗时和响应截断提示，操作区可在窄屏换行。
- 「载入」只恢复请求与结果，不会自动发送，也不会改写原始 URL、请求头或请求体。
- 清空历史前需要确认，会删除当前接口的全部记录，包括被筛选隐藏的记录。
  对话框首先聚焦「取消」，取消或 Escape 不会清空数据。
- 请求处理中禁用载入、删除和清空；搜索和筛选仍然可用。

## 展示隐私与边界

列表、提示文字和操作按钮名称不会显示 URL 内嵌的用户名/密码，
会遮蔽已识别的认证查询参数和 URL fragment；无法解析的 URL 不会直接回显原文。
搜索仅匹配已经脱敏的地址与环境名称，不搜索隐藏凭据、请求头、请求体或响应正文。

这不是通用秘密检测器：路径、自定义查询参数、环境名称和错误信息仍可能包含用户提供的内容。
原始请求保留在当前标签页的 sessionStorage 中，以便精确重放；载入后的编辑器会展示可编辑的原始数据。
不要在共享设备上保留敏感调试历史，也不要把真实凭据或私人响应放入截图和公开文档。
