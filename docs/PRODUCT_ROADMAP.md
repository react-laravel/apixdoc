## 2026-09-12：环境化调试、认证、历史与 cURL

已落地：
- 调试器可选择/记住项目环境，使用默认环境；支持环境变量和临时变量覆盖、递归引用、循环/缺失变量提示。数值变量保留原始精度，JSON 字符串插值自动转义。
- 请求方法、地址、路径参数、查询参数、请求头和请求体均可临时调整。支持 OpenAPI `{id}` 和整段 `:id` 路径占位符，正确编码路径和查询值。
- Bearer、Basic 和 API Key（请求头/查询参数）认证；原始请求体和 URL 编码表单；1–60 秒超时、取消、响应状态/大小/耗时。
- 请求预览、实际发送和 cURL 使用同一份构造结果。导入的 cURL 与历史快照默认按原文发送，保留签名查询的编码以及字面量模板内容；需要时可重新启用占位符解析。
- 常用 cURL 参数支持引号、转义、续行、数据、请求头、Basic、查询、超时。未支持的选项、文件读取、Shell 运算和不兼容 GET/HEAD 请求体会明确报错；重定向行为差异在导入预览中显示。
- 历史按账号/项目/接口隔离，使用当前标签页存储，最多 20 条/1 MB；大响应保留前 64 KB 并明确标记，截断响应不能写回文档。载入历史不会自动发送。
- 文档默认值变化会更新仍在继承的字段，保留手动覆盖/删除；cURL 和历史请求不受文档默认值变更影响。账号或项目范围变化时丢弃旧的在途结果。
- JSON 变量模板支持高亮、美化、压缩、源位置校验和解析后结构预览，示例中的 `{{userId}}` 不再被误判为普通 JSON 错误。
- 环境/全局配置读取增加项目成员校验；公开项目详情不返回环境、全局请求头和全局参数。两个配置写接口复用设置校验和原子更新，避免部分更新清空其他配置。

验证证据：
- 256 项测试通过；lint 0 错误、5 项原有警告；生产构建和 TypeScript 通过。
- 真实 Postman Echo 请求验证了环境、路径/查询编码、继承请求头、JSON 插值、Basic、API Key 和 URL 编码表单。未转发应用登录 Cookie；导出 cURL 再导入后的请求内容一致。
- 浏览器验证了刷新后的历史载入、精确重放、JSON 模板美化、共享默认值即时更新与临时修改保留；移动端/深色模式无页面横向溢出。
- 生产模式新账号验收：浏览器运行错误 0；模拟缺少 `crypto.randomUUID` 时仍能创建参数行和历史记录。
- 真实非成员账号访问环境和全局配置得到 403；公开项目详情仍返回 200，运行配置数组为空。
- 本地证据：`output/playwright/request-*.png`、测试/构建日志和验收脚本。独立验收数据已清理，证据不提交到源码。

## 2026-09-12：独立文档、只读权限与原生格式导出

已落地：
- `/docs/{projectId}?endpoint={endpointId}` 独立文档页，包含目录搜索、接口链接、Markdown 表格/代码、参数、请求头、请求/响应结构与 JSON 示例。支持手机阅读和深色模式。
- 私有文档要求登录并校验组织成员关系，登录后回到原接口；公开文档允许匿名访问。取消公开后，新文档访问需要登录，匿名导出被拒绝。
- 项目权限集中判断：owner/admin 管理发布和项目删除；member 可编辑接口、目录和运行配置但不能变更公开状态；viewer 只能查看文档，不能读取运行凭据或调用写接口。前端同步隐藏/禁用对应操作。
- 公开/只读 DTO 隐藏环境与全局配置，清理 URL 中的已识别认证信息，并对结构化认证示例（含模板、无效 JSON 的可识别字段）脱敏。Markdown 原始 HTML 不执行，危险链接不可点击。
- 原生项目可导出 OpenAPI 3.1 JSON/YAML 和 Postman Collection 2.1，保留当前模型中的参数、结构、响应及精确数值。Authorization 使用 OpenAPI securitySchemes，Postman 路径变量转换为 `:id`。
- 复制接口保留参数、请求头、请求体、响应结构；删除需要确认。修复跨项目目录引用与直接 API 创建目录循环的问题，读取项目目录时不混入历史异常关联的其他项目接口。

验证证据：
- 299 项测试通过；TypeScript、生产构建通过；lint 0 错误、5 项原有警告。
- 使用真实 owner/member/viewer 账号和匿名访问验证私有登录回跳、只读 UI 与写入 403、普通成员配置修改、管理员发布/撤回、匿名文档和安全导出。
- 浏览器实际复制并删除接口，校验关联参数/请求体/响应结构；下载三种格式并检查内容与大整数精度。
- 公开 HTML 与导出内容未出现验收凭据；损坏的跨项目目录关联未泄漏其他项目接口；Markdown 注入未执行，移动端无页面横向溢出。
- 验证产物保留于本地 `output/playwright/docs-*`，不提交测试账号或导出内容。

未完成与下一步：
- OpenAPI/Postman 导入尚未实现。本轮先完成了发布依赖的权限与查看链路。导入前需要扩展规范存储，保留 `$ref`、组合 Schema、枚举、多媒体类型、非数字响应码等信息，不能只导入路径而丢弃原始定义。

已落地：
- OpenAPI 3.0 / 3.1（JSON、YAML）和 Postman Collection 2.1 文件上传或粘贴导入。支持预览、重复方法/路径提示、追加跳过，以及管理员确认项目名称后的整体替换。
- 保存原始文件、接口定义和编辑基准。私有原始文件可下载；内部同格式导出合并当前修改，保留未改动的引用、组合结构、枚举、命名示例、多个媒体类型、默认/范围响应、扩展字段与集合脚本。删除接口不会在导出时重新出现，移动目录同步到导出结果。
- 规范定义、版本、集合全局配置或变量有冲突时，在预览阶段报错。保存使用数据库事务和预览指纹，绑定项目内容、上传文件与导入模式；过期预览和并发提交返回 409，失败时不留下部分数据。
