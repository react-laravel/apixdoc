# ApiX Docs 产品迭代

目标：持续迭代为功能完整、可供团队日常使用的商业化 API 文档与调试产品。

交付方向已确认：兼顾私有部署与 SaaS，先补齐核心功能。以下阶段是实施顺序，不是缩小最终目标；只有核心流程完成并通过实际运行验证后，才能判定商业化目标完成。

## 现有基础

- `824d1d0`：接口工作台布局、手机适配、保存状态、未保存修改提醒、取消拖拽修复、文件夹编辑、项目设置持久化。

## 每轮交付要求

1. 先追踪 UI、请求、权限与数据库的真实流程，再实现功能。
2. 针对数据正确性、状态恢复、回归风险添加有意义的自动化测试；验证桌面、手机和深色模式。
3. 使用独立本地测试数据，保留可复核的运行证据并清理临时数据。
4. 每轮记录已完成能力、未覆盖范围及下一阶段；不把未实现功能标为完成。


## 2026-09-12：JSON 工作台与响应查看

已落地：
- `/dashboard/tools/json` 独立工具，可导入文件、编辑、校验、美化、压缩、折叠、搜索、复制、下载和放大查看。
- JSON 结构树支持字段/值搜索、复制原值、复制 JSON Pointer；数组每批 100 项，批量展开最多五层/50 个分组。
- 请求体 Schema、请求示例、响应示例、在线响应复用工作台。JSON 处理基于源码 token，不将大整数、长小数或字符串转义转成 JavaScript 值再序列化。
- 在线测试新增响应大小、可编辑 Bearer Token、请求取消；修复空请求体回退到旧示例以及 URL 斜杠/查询参数拼接；切换编辑标签保留测试结果。

验证证据：
- 195 项测试通过，包含 JSON 精度/错误/边界、编辑工作流、代理取消和请求构造回归；TypeScript 及生产构建通过。lint 0 错误，5 项原有警告。
- 生产构建本地启动后，验证 50,000 项数组分页搜索、文件导入、美化撤销、路径复制、原文下载、错误定位、手机/深色界面；浏览器运行错误 0。
- 使用独立本地数据验证请求体保存、响应导入并保存、切换接口与刷新后的数值一致性。代理 UI 使用可控回包，服务端取消另由路由测试覆盖。
- 浏览器证据位于本地 `output/playwright/json-*.png` 与对应测试/构建日志；这些临时验证产物不进入源码提交。
- 生产模式验证按已有部署文档设置 `AUTH_TRUST_HOST=true`，并临时指定本地 `AUTH_URL`，没有修改线上配置。

剩余范围：环境切换与变量解析、路径参数和完整认证方式、请求历史与 cURL、OpenAPI/Postman 导入导出、只读文档分享、权限与协作、商用运维仍未完成。JSON 工作台完成不代表商业化总目标完成。
