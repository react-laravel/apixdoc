# 账号管理与恢复

## 个人设置

右上角账号菜单进入 `/dashboard/account`。支持修改显示姓名、验证当前密码后改密、退出全部设备，以及删除自己的账号。姓名使用账号版本检查，旧页面不会覆盖其他已保存修改。密码至少 8 位、不超过 bcrypt 的 72 字节限制，保留输入中的空格。

改密、密码恢复、退出全部设备、停用、删除和角色变更会递增登录版本。旧会话在下次请求时失效，恢复或重新启用不会使旧会话复活。迁移前的有效会话按版本 0 兼容；已开始并通过身份检查的请求可能完成，不承诺追溯撤销正在执行的请求。

登录邮箱当前只读，后续接入邮件验证后再提供邮箱变更。

## 平台用户管理

平台管理员在 `/dashboard/users` 搜索姓名/邮箱、筛选账号状态并分页查看账号。每页 50 项，创建与操作失败直接显示原因；旧版本操作返回 409，可关闭弹窗并刷新列表。

- 停用：禁止登录、撤销会话和相关待处理邀请；保留组织成员关系和内容。团队页面显示停用状态，不能向停用成员转移所有权。
- 启用：重新允许登录，已撤销的会话和邀请不恢复。
- 删除：可恢复的逻辑删除，移除所有组织成员关系，撤销待处理邀请和登录；保留账号邮箱、内容作者及项目/接口。组织所有者须先转移所有权。
- 恢复：恢复为普通账号，不恢复平台管理员权限或组织成员关系。原密码可使用，也可另行生成恢复链接；加入组织需要重新邀请。
- 角色：普通账号或平台管理员；变更后需要重新登录。
- 敏感管理操作要求平台管理员输入自己的当前密码。不能在用户管理中修改自己的状态，应使用个人设置。始终保留至少一位正常的平台管理员。

账号与团队身份变更共用数据库事务锁，避免删除与加入组织、所有权转移或管理员互相停用的竞争。成功变更同时写入审计；组织内停用/启用和邀请撤销也更新团队版本与事件记录。

删除不等于匿名化或永久清除，邮箱仍被保留且不能被新账号复用。应用未提供永久清除接口。

## 一次性账号恢复

忘记密码页面 `/recover` 引导联系平台管理员。管理员确认身份后，在用户管理中生成半小时有效的一次性链接，手动私下交给账号本人；应用不会自动发送邮件。

链接密钥使用 32 字节随机数，数据库仅保存 SHA-256 摘要。密钥放在 URL fragment 中，页面不索引、禁用来源引用；成功后清除地址栏中的密钥。一次性消费、密码更新、会话失效及审计写入在同一事务提交。并发使用仅一次成功；过期、撤销、重发以及账号停用/删除会使旧链接失效。

恢复链接只能在刚生成时查看，可复制或手动选择。管理员可撤销未使用链接。密码及链接密钥不会进入操作审计。

## 接口

- `GET /api/account`：当前资料与持有所有权的组织。
- `PATCH /api/account`：`name`、`version`。
- `POST /api/account/security`：`action=password|signout|delete`、`version`、`currentPassword`；改密另传 `password`，删除另传完整邮箱 `confirmation`。
- `GET /api/users?q=&status=&cursor=`：平台用户列表，返回 `items`、`total`、`next`。替换旧的未分页数组响应。
- `POST /api/users`：创建账号，`email`、`name`、`password`、`role`。
- `PATCH /api/users/{id}`：`action=disable|enable|delete|restore|role|recovery|revoke-recovery`、`version`、`currentPassword`；删除另传 `confirmation`，角色另传 `role`。
- `DELETE /api/users/{id}`：同逻辑删除，必须提供 JSON 确认与当前密码，不再永久删除。
- `POST /api/account/recovery`：`token`、`action=inspect|reset`；重设另传 `password`。

所有写接口检查 JSON 请求和来源。响应不包含密码、会话版本或恢复摘要。列表只向平台管理员开放。迁移增加账号状态、账号/会话版本和恢复链接摘要字段，默认现有账号保持正常。

## 验证与后续

`npm run test:accounts` 仅操作 localhost/127.0.0.1 上的独立验收账号，覆盖权限、并发资料变更、改密、恢复单次消费/过期/撤销、管理员竞争、删除保留、重新邀请、分页和审计内容，并清理数据。单元测试补充旧登录与最后一位管理员保护。

待继续：自动恢复邮件、邮箱验证与变更、SSO、登录与敏感操作的统一限流、账号永久清除政策、配额/套餐、备份恢复和告警。这轮核心账号流程完成不代表商业化总目标完成。
